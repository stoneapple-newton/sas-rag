# SAS RAG MCP Docs

This directory holds raw research inputs, curated wiki notes, and the documentation activity log.

## Structure

- `raw/` - uncurated research notes, source captures, and temporary import material.
- `wiki/` - concise, linked, Karpathy-style project wiki pages.
- `README.md` - this documentation area guide.
- `log.md` - documentation changes, raw imports, decisions, and follow-ups.

## Raw to Wiki Flow

1. Add uncurated Markdown or text material to `docs/raw/`.
2. Use the `safe-wiki-manager` skill to curate raw material into short wiki pages.
3. Keep raw source backlinks in the generated wiki page.
4. Update `docs/wiki/README.md` when adding wiki pages.
5. Record imports and major documentation edits in `docs/log.md`.

## Wiki Style

- Keep pages short and topic-oriented.
- Prefer links and dense notes over long essays.
- Link related SAFe stories when a wiki page supports planning or implementation work.
- Keep raw copied material in `docs/raw/`; keep curated project knowledge in `docs/wiki/`.
